# /rank-opportunities

Read Search Console-based striking-distance, decay, and cannibalization opportunities.

Run `bash skills/rank/scripts/rank-command.sh rank-opportunities <site-uuid>` only after the user has configured `RANK_API_KEY` and `RANK_API_URL`. The wrapper checks the exact command, method, and route in the authenticated capability catalog before calling it. If unavailable, explain the missing gateway capability and stop.

State the Search Console date window and whether data is measured or unavailable.
