# /rank-setup

Check connected sites and receive official connect links for site and Search Console.

Run `bash skills/rank/scripts/rank-command.sh rank-setup` only after the user has configured `RANK_API_KEY` and `RANK_API_URL`. The wrapper checks the exact command, method, and route in the authenticated capability catalog before calling it. If unavailable, explain the missing gateway capability and stop.

Never request a site password or OAuth token in chat. Open only links returned by the gateway.
